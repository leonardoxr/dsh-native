# Support

## Get help

Before opening an issue:

1. Update to the [latest release](https://github.com/leonardoxr/dsh-native/releases/latest).
2. Check the [README](README.md) and existing [issues](https://github.com/leonardoxr/dsh-native/issues).
3. Confirm the server URL begins with `https://` and works in a regular browser.

For reproducible application problems, open a [bug report](https://github.com/leonardoxr/dsh-native/issues/new?template=bug_report.yml). For proposed behavior, use the feature request form.

This is a volunteer-maintained project; response times are best effort. General support questions may be closed if they cannot be reproduced or are specific to the remote web application rather than DSH Native.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
